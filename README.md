# Countdown November 19

Einfache Android-App (Kotlin) mit Countdown bis **19. November 2026, 16:00 Uhr**.

## Features
- Schöne Countdown-Anzeige (Tage, Stunden, Minuten, Sekunden)
- **Homescreen-Widget** (zeigt den Countdown direkt auf dem Startbildschirm)
- Modernes dunkles Design

## So baust du die App

1. Klone das Repository:
   ```bash
   git clone https://github.com/zsenike/countdown-november-19.git
   ```
2. Öffne den Ordner in **Android Studio** (Giraffe oder neuer).
3. Warte, bis Gradle fertig synchronisiert hat.
4. Schließe dein Handy an oder starte einen Emulator.
5. Klicke auf **Run** ▶

## Widget hinzufügen
Nach der Installation:
1. Lange auf den Startbildschirm drücken
2. **Widgets** auswählen
3. Nach **Countdown** suchen und hinzufügen

## Ziel-Datum
19. November 2026, 16:00 Uhr (lokale Zeit)
